# 10주차 확정 라벨 규칙

버전 1, 2026-11-10. 고정 카메라 주간 영상의 개발용 규칙이며 제안서의 정답 정의를 따른다.

- 공통 키는 `video_id, frame_id, timestamp_s, slot_id`다. `frame_id`는 원본 영상의 0부터 시작하는 디코딩 순서이며 명목 시각은 `frame_id / FPS`다. CSV의 소수 셋째 자리 표시는 반올림 값이다.
- `occupied`: 지정한 주차면 경계에 차량 차체가 일부라도 겹친다. 완전히 주차될 때까지 기다리지 않는다.
- `free`: 차체가 완전히 빠져나갔거나 차량이 없다. 그림자만 남은 경우는 점유가 아니다.
- `unknown`: 가림·해상도·경계 문제로 사람이 판단할 수 없다. `reason`에 사유를 적고 분류 지표에서는 제외하되 표본 수를 공개한다. 검출기의 보류 출력과 구분한다.
- 현재 사용할 경계는 `configs/roi.shared_carpark.final.json`의 A03~A12·A15~A24, 20칸이다. 팀원 원본의 69칸 검출 코어 영역과 섞지 않는다. 경계를 바꾸면 정답도 재검수하고 데이터 버전을 올린다.
- `data/labels/pilot.shared_carpark.csv`는 팀원 원본의 형식만 바꾼 인계본이다. `pilot.shared_carpark.reviewed.csv`는 보정한 경계에 대한 에이전트 검수본이며 `reviewed_by=agent_visual_review`로 출처를 명시했다. 독립 팀원의 사람 재검수를 뜻하지 않는다.
- 검수본에서 A23/151번·A20/377번 프레임의 `unknown` 2건을 `occupied`로 바꿨다. 확대 화면에서 경계 안에 차체 일부가 남아 있고 전후 0.25초 시퀀스에서도 확인했다. 변경 사유와 원본 값은 `manifests/stage10_review.json`에 남겼다.
- 사건 구간과 무작위 10%의 독립 팀원 재검수는 최종 평가 전에 별도로 수행한다. 테스트 정답을 임계값·필터·시간 안정화 선택에 사용하지 않는다.

현재 검수본은 3칸·10시점·30행이며 free 21·occupied 9다. 20칸 전체의 보정 라벨이나 최종 테스트 정답이 아니다. A20·A23만 양 상태 표본이 있고 A07은 빈자리만 있으므로, 칸별 보정 전에 부족한 상태의 자료를 확보해야 한다.

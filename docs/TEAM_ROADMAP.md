| 10 데이터 | 지창윤·이도훈 | 영상 사용 조건 확인 | 영상 목록·분할·라벨 규칙·10칸 이상 ROI 재사용 |

## 작업 경계
- 데이터 담당: `data/`, `configs/`의 출처·분할·라벨·ROI. 원본 영상은 별도 전달한다.
- 특징 담당: `src/parking_monitor/`의 픽셀 비율·라플라시안 모듈과 작은 입력 테스트.
- 안정화 담당: 시간 기반 상태 전이와 초기화 테스트.
- 통합 담당: CLI·화면·로그·평가 연결, 재현 안내.
- 같은 파일을 함께 수정할 때는 이슈에서 먼저 담당을 조율한다. 후속 모듈 이름과 함수는 구현 PR에서 합의하며 미구현 기능을 동작한다고 기록하지 않는다.

## 인계 시 반드시 남길 내용
입력 파일의 위치와 사용 조건, 코드 버전, 설정, 실행 명령, 실제 결과, 미완료 조건을 PR에 남긴다. 보정·검증·최종 테스트를 분리하고 최종 테스트로 설정을 고르지 않는다. 성능 목표는 AGENTS.md의 목표이며 측정 전에는 달성으로 표시하지 않는다.

## 현재 판단
2026-11-10 기준 단계 10의 최소 산출물은 완료했다. 공통 영상 20칸 ROI·개발용 분할 버전 2·라벨 규칙·파일럿 검수본을 확정했으며 [검수 기록](stage10-review.md)과 `data/manifests/stage10.freeze.json`을 따른다. 다음 개발은 단계 11의 칸별 양 상태 보정 자료 보완과 픽셀 기준선이다. 독립 팀원 정답 재검수·각자 환경 재현, 다른 시점 ROI·정답·최종 평가 규모 확보는 별도 공동 작업으로 남아 있다.

## 12주차 정량 평가 프로그램 구현 (2026-11-23)

- `evaluate validate`, `freeze`, `test`로 검증 비교, 설정 동결, 최종 테스트를 실행한다. 평가 목록에서 영상·ROI·정답·입출차 사건을 교체한다. 기본 설정은 픽셀 비율, 라플라시안, 결합, 연결성분 필터와 시간 안정화 조합 8개를 비교한다.
- 정량 평가 명령·입력·처리·실행 코드를 `src/evaluation/` 패키지에 모았다. `parking_monitor evaluate`에서 실행하며, 설정 동결에는 `src/` 기준 코드 경로와 해시를 기록한다. 이동 후 패키지 탐색과 자동 테스트 53개를 확인했다.
- 이미 있는 픽셀 비율 및 공통 분류 지표를 재사용하고 라플라시안 평균 절댓값, 일치 판정, 영상 시각 기반 안정화를 연결했다. 실행별 혼동표·F1·거짓 빈자리율·확정 비율, 처리시간·FPS, 사건별 지연·미검출을 파일로 남긴다. 속도는 표시창 없이 디코딩·검출·CSV 기록을 측정한다.
- 자동 테스트 53개와 환경 점검을 통과했다. 서로 다른 FPS의 합성 촬영본 두 개에서 검증·동결·최종 테스트를 실행했고, 재실행한 예측·사건·임계값 파일이 일치했다. 공통 영상 679프레임에서 기존 픽셀 기준선 결과 파일 8개가 변경 전과 바이트 단위로 일치했다.
- 학교 앞 촬영본에는 로드맵 기준의 보정·검증·최종 테스트 정답과 입출차 사건 자료가 필요하다. 현장 성능 결과와 시연 구성은 이 자료로 평가한 뒤 확정한다. 실행 방법과 목록 예시는 [README](../../README.md#알고리즘-정량-평가)를 따른다.

## 11주차 픽셀 비율 기준선 인계 검토 (2026-11-23)

- **10주차 최소 산출물 완료, 11주차 진행 중.** 제안서 PDF 2~4쪽과 최종 DOCX의 처리·데이터·일정 기준을 대조했다. 팀원 공유본에 적응형 역이진화·미디언·형태학·ROI 픽셀 비율, 두 임계값과 보류 판정, r 분포·2×3 혼동표·형태학 비교표 생성이 있다. 현재 개발 패키지에는 반영 전이다.
- 프로젝트 Windows 환경(Python 3.12.14, OpenCV 4.14.0, NumPy 2.5.4)의 임시 복사본에서 팀원 테스트 23개가 통과했다. 기존 저장소 테스트도 29개가 통과했다. 팀원 원본 영상 679프레임 전체 처리 후 같은 설정으로 다시 실행해 CSV·JSON 6개가 바이트 단위로 일치했다. 공유된 `mac_check`와는 입력·코드 해시 및 30행 판정이 일치했으며 r은 30행 중 16행에서 달랐다(최대 절대차 0.004155, 원인 미확인).
- 파일럿은 3칸×10시점 30행 중 불명 2행을 제외한 28행을 보정과 평가에 함께 사용했다. A07에는 칸별 양 상태 표본이 없어 통합 임계값을 임시로 적용했다. 이 실행의 F1 1.0은 표본 내 동작 확인값이다. 확정 20칸 ROI와 검수본 30행을 임시 변환해 저장소의 분할 버전 2로 실행한 결과, 30행 모두 보정용이었고 검증 표본은 0행이었다. 공유 코드 기본 설정에서 칸별 임계값을 만들 수 있었던 곳은 A20·A23 두 칸이었다.
- 통합 전 영상 ID(`shared_carpark`)와 0부터 시작하는 프레임 번호를 팀원 실행기에 연결해야 한다. 현재는 파일명 일치를 요구하고 프레임을 1부터 읽는다. 저장소의 반개구간 `[시작, 끝)`과 최소 10초 간격 규칙을 재사용하고, 형태학 비교 단계에서 테스트 정답 사용을 막아야 한다. 임계값 없는 칸은 평가에서 빠지므로 공식 평가 전에 대상 칸 전체의 보정을 확보한다.
- 공유 영상·ROI·파일럿 정답은 기존 인계 자료와 같다(영상·ROI 해시 및 정답 본문 대조). 다른 시점 후보 2개는 이미 확보되어 있다. 보정 칸의 양 상태 정답과 별도 검증 구간의 ROI·정답을 먼저 확보하고 동일 설정으로 r 분포와 초기 혼동표를 재생성한다. 라플라시안·결합·시간 안정화와 A~D 비교, 통합 성능 측정, 최종 평가는 후속 단계다.
- 팀원이 제안한 A52는 5초 무렵 출차 중이며 7.5초에도 차체 일부가 원본 ROI에 남아 있고 9초에는 완전히 벗어난다. 기존 확정 20칸 밖의 보정 후보라 확정 ROI·사람 정답에는 편입하지 않았다. 검토 시계열·프레임과 임시 실행 결과는 `tmp/stage11-handoff-review-2026-11-23/`에 있다.

# 10주차 개발용 데이터·ROI 확정

2026-11-10 에이전트 검수. 제안서의 완료 기준인 **저장 영상에서 10개 이상 칸 좌표 재사용**을 충족했으므로 10주차 최소 산출물 단계는 완료한다. 이번 확정 범위는 공통 영상의 20칸과 버전 2 개발용 분할·라벨 규칙이다. 최종 성능평가 데이터 동결, 사람 정답 독립 검수, 다른 시점 ROI 완성이나 검출 성능 달성을 뜻하지 않는다.

## 확정한 파일

| 용도 | 파일 |
| --- | --- |
| 원본·출처·영상 목록 | `data/manifests/videos.csv`, `upstream_assets.json`, `sample_validation.json` |

| 확정 파일 목록·해시 | `data/manifests/stage10.freeze.json` |

팀원 원본 3개, 69칸 후보 설정, 형식만 변환한 원본 정답은 그대로 보존했다. 실제 사용할 칸은 A03~A12와 A15~A24다. 같은 인접 두 주차열의 연속 10행을 선택하고 긴 밴과 섬 경계가 있는 위쪽 두 행을 제외했다. 검출 결과를 보며 잘 맞는 칸을 고른 것이 아니다. 20칸 경계는 주차선 바로 안쪽으로 보정했다.

## 실제 검수 범위

- 공통 영상 679프레임 전체 디코딩과 해시·해상도를 검사했다. 1초 간격 및 파일럿 시점·끝 프레임을 합친 38프레임의 20칸 오버레이를 시각적으로 검토했다. 큰 위치 어긋남은 보이지 않았으며 카메라 이동량을 수치 측정한 결과로 해석하지 않는다.
- A23의 4~9초, A20의 13~18초를 0.25초 간격의 확대 시퀀스로 검토했다. 151번 A23·377번 A20은 차체가 보정한 주차면 안에 남아 있어 검수본에서 점유로 바꿨다. 팀원 원본의 불명 값과 사유는 보존했다.
- 20칸의 볼록성·교차·범위·중복 ID·겹침·빈 마스크, 원본/50% 마스크, 저장/재로드를 검사했다.
- 다른 두 영상은 전체 5초 간격 개요와 기존 분할 경계 주변 1초 간격 시퀀스를 확인했다. lot_1의 박스 트럭 출차와 전경 승용차 출차, lot_2의 작업 트럭 진입이 예전 분할에 걸려 있었다. 한 사건이 한 구간에 들어가도록 경계를 옮겼다. 다른 영상 ROI가 없고 시각 검토는 시간 표집이므로 독립 사람 연속 사건 검수가 끝났다고 기록하지 않는다.

| 영상 | 보정 `[시작, 끝)`초 | 검증 | 테스트 |
| --- | --- | --- | --- |
| shared_carpark | 0~679/24 (약 28.292) | 없음 | 없음 |
| olgarose_lot_1 | 0~60 | 70~110 | 120~145 |
| olgarose_lot_2 | 0~55 | 65~85 | 95~125 |

각 분할 사이 10초 간격을 유지했다. 공통 영상은 끝까지 보정에 포함해 파일럿 30행 전체가 보정 구간 안에 있다. 검출 성능을 보고 분할을 바꾸지 않았으며, 아직 최종 평가용 동결은 아니다. 표집 후보는 보정 141·검증 58·테스트 54프레임이다. 최종 테스트 200프레임 목표까지 146프레임이 부족하며 추가 사건과 새 자료가 필요하다. 이는 후속 데이터 확대 조건으로 남긴다.

## 사용 조건과 검수 주체

사용자가 현재 영상을 “MIT 오픈소스 동영상”이라고 확인했으므로 그 근거로 수업 프로젝트 개발·평가용 채택을 확정했다. 공통 영상 저장소의 MIT 고지는 원문을 보관한다. 다른 저장소의 독립적으로 확인된 라이선스 필드는 그대로 두고 사용자 확인과 구분했다. 원본 영상은 계속 Git에서 제외한다. 상세는 `data/USAGE_REVIEW.md`와 `data/manifests/rights_review.json`에 있다.

검수자는 에이전트이며 독립 팀원의 사람 정답 검수나 다른 PC 재현을 완료했다고 서명하지 않는다. 11주차의 다음 작업은 현재 20칸에서 칸별 양 상태 보정 자료를 보완하고 픽셀 기준선을 구현하는 것이다. 다른 두 시점 ROI·정답·연속 사건 주석과 테스트 규모 확대는 최종 평가 전에 완료한다.

## 재현과 변경 관리

```powershell
.\.venv\Scripts\python.exe scripts/validate_stage10.py
.\.venv\Scripts\python.exe scripts/validate_stage10.py --with-videos
.\.venv\Scripts\python.exe -m parking_monitor roi-preview data/raw/faisal_ajao/video.mp4 --roi configs/roi.shared_carpark.final.json --frame 377 --output tmp/stage10_review/final20.png
```

첫 명령은 영상 없이 확정 파일 해시·좌표·원본 보존·라벨 변경·분할·프레임 목록을 검증한다. 두 번째는 로컬 원본 3개의 해시와 끝까지 디코딩한 프레임 수도 확인한다. 영상별 실제 디코딩 수는 679·2247·3770이다.

시각 증거는 Git 제외 `tmp/stage10_review/`에 둔다. 재생성은 원본 영상의 해당 프레임을 읽어 ROI 오버레이를 그리고, `stage10_review.json`의 프레임 목록·시퀀스 간격대로 배열하면 된다. 확정 파일을 바꾸려면 사유·검수 결과와 새 버전을 함께 기록하고 해시 목록을 갱신한다. 기존 해시를 검증 없이 바꾸거나, 테스트 검출 결과에 맞춰 분할·칸을 고르지 않는다.
